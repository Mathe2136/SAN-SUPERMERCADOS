# SAN Supermercados

Protótipo de catálogo de produtos com carrinho, desenvolvido para praticar componentes e estado em React.

## Funcionalidades
- Exibição de produtos com nome, preço e imagem.
- Inclusão de produtos no carrinho.
- Contagem dos itens adicionados.
- Mensagem de confirmação ao adicionar um produto.

## Tecnologias
HTML, CSS, JavaScript e React 18. React e ReactDOM são carregados por CDN; Babel transforma o JSX no navegador.

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `san.html` no navegador.
3. Mantenha uma conexão com a internet para carregar as bibliotecas e imagens externas.

## Organização
- `san.html`: estrutura da página, estilos e componentes React.

## Conceitos presentes no código
Componentes reutilizáveis, propriedades (props), estado com `useState`, eventos e renderização de listas.

## Estado do projeto
Protótipo de estudo. O carrinho guarda apenas os nomes dos itens durante a sessão da página. Não há cálculo de total, remoção de itens, persistência, pagamento ou back-end.
